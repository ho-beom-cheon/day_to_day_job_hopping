# 백엔드 이직 과정 26주 편성 초안

8년차 SI 개발자·하루 90~120분·주 5학습일을 기준으로 한 **편집용 목차**다. 기본 개념은 요구사항 변경, 기존 코드 수정, 데이터 정합성, 외부 연계, 배치, 회귀 테스트에 적용한다. 정의 암기 문제로 난이도를 채우지 않으며 인프라·분산 시스템 이론은 필요한 범위로 제한한다. 월차는 교육 모듈이며 실제 달력 월과 일치할 필요는 없다. 주차는 1부터 26까지, 학습일은 1부터 130까지 연속 번호로 부여한다. 각 학습일에는 구현·테스트·설계 검토 과제를 포함한다. 일간·주간·월간·최종 시험을 편성하며, 세부 문항 수와 합격 기준은 발행 전에 확정한다.

## 평가 배정 초안

- 일간 시험 130개: 각 학습일에 짧게 배정한다. 학습 본문의 확인 문제 제출과 시험 응시는 서로 다른 사용자 기록이므로 두 흐름을 함께 검증한다.
- 주간 시험 26개: 원칙적으로 각 주 5일차에 배정한다. 마지막 주는 최종 시험과 겹치지 않도록 4일차에 둔다.
- 월간 시험 6개: 월차의 마지막 주에 배정하되 해당 주 주간 시험과 다른 날에 둔다. 6월차는 최종 시험과도 다른 날로 배정한다.
- 최종 시험 1개: 26주 5일차에 배정한다.
- 시험 총수는 163개다. 문항 수·시간·합격선·중복 출제 정책은 1주차 평가 초안을 검토한 뒤 확정한다. 출제용 문제 원형은 여러 시험에서 재사용할 수 있으나, 시험마다 문제 버전을 고정한다.

## 범위 검토 항목

- Java와 Spring의 설명은 현재 프로젝트가 사용하는 Java 21·Spring Boot 버전에 맞춰 작성한다.
- 금융·공공 사례는 일반적인 시스템 설계 예시로 쓴다. 실제 기관의 업무 규칙·규정이라고 단정하지 않는다.
- 일간 시험은 매 학습일, 주간 시험은 매주, 월간 시험은 매월, 최종 시험은 마지막 주에 둔다. 월말 주간 시험과 월간 시험은 서로 다른 날로 배정해 하루 학습량을 조정한다.
- 학습일마다 동일한 문제 수를 기계적으로 배정하지 않는다. `READ_ACK`와 `ALL_PROBLEMS_ATTEMPTED`를 학습 목표에 따라 구분한다.
