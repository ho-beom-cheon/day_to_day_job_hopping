# 1주차 편집·기술 검수 기록

검수일: 2026-09-23
기존 검수 대상: 경력 5년 이상, 하루 90~120분, 일간 시험 매일·주간 시험 매주.

2026-09-27 기준 대상은 8년차 SI 개발자로 조정했다. 아래 2026-09-23 검수 결과는 종전 기준의 기록이며 새 기준의 난이도 승인을 뜻하지 않는다. 특히 확인 문제 5개 중 4개가 난이도 2이고, 일부 보기의 오답이 지나치게 명백하다. 문제·해설·실습을 요구사항 변경과 유지보수 판단 수준으로 재작성하고 독립 검수하기 전에는 발행하지 않는다.

| 문제 참조 | 구조 확인 | 학습 확인 문제 5개와 시험용 문제 15개, 고유 ID 20개. 일간 5개 시험과 주간 10문항의 참조가 모두 존재 |
| 정답 형식 | 구조 확인 | 20개 모두 A~D 보기, 보기 내 유효한 정답, 해설 포함. 정답 위치는 A/B/C/D 각 5개 |

## 이번 수정

- 개념 이름이나 API 반환값만 묻던 기본 문제를 요청 중복, 테넌트별 캐시 키, 가변 Map 키, record의 얕은 불변성, 금액 정규화 상황으로 바꿨다.
- 외부 ID가 둘 다 누락됐을 때 `Objects.equals`만으로 같은 요청이라고 판단하는 오류를 문항에 반영했다.
- 일간 시험이 2문항인 편집 초안에서 합격선 70%는 실제로 2/2 정답을 요구한다. 표현과 계산이 일치하도록 100%로 적었다. 재응시 2회는 운영 확정값이 아니다.
- 주간 시험의 새 상황형 문항 5개를 섞어 기존 일간 시험 문항의 단순 재시험 비율을 50%로 낮췄다.
- 학습 과제는 별도 회사 코드가 없어도 작성할 수 있게 작은 주문·청구서 예제로 바꿨다.

## 운영 발행 전 남은 검수

1. 문항의 정답은 구조적으로 연결됐지만, 학습자·기술 검토자가 오해 가능성과 난이도를 실제로 검토해야 한다. 일부 일간 문항은 도입 복습 수준이다.
2. 주간 시험 10문항 중 5문항은 일간 시험에서 이미 노출된다. 성취 판정에 쓰려면 미공개 문항 비율과 재출제 간격을 확정해야 한다.
3. `lab.task`와 `lab.acceptanceCriteria`는 편집 자료의 별도 필드다. 적재 도구는 이를 학습 `body_markdown`에 포함하고 `lab.reviewerGuide`는 학습자에게 노출하지 않아야 한다.
4. 원고의 공식 URL은 기술 근거를 찾기 위한 것이며, 운영 발행 전 URL·사용 권한·정확성을 다시 확인한다.
5. 2~26주차 원고, 월간·최종 시험, 적재 도구가 아직 없다. 이 1주차만으로는 전체 과정 발행 검증을 통과할 수 없다.

검수 결론: **1주차 편집·구조 초안으로 사용 가능. 운영 DB 발행 불가.**
