# 이슈 초안: 알림·Notion·Slack·Web Push 설정 흐름 구현

## 배경

작업 19에서 외부 연동 상태와 알림 설정을 사용자가 확인할 수 있어야 하며 외부 장애가 핵심 업무 저장과 분리되어야 한다.

## 범위

- 알림 설정 aggregate와 ETag/If-Match 갱신
- Web Push 공개 설정 및 서버 준비 상태
- Notion 연결 진단과 단방향 동기화 원칙
- Slack 서버 구성 여부와 사용자 발송 설정
- `/settings/integrations` 반응형 화면
- 실제 외부 자격증명이 없는 상태를 명확히 표시

## 완료 조건

- 설정 동시 변경은 412로 보호한다.
- 비밀값은 API·UI·로그에 노출하지 않는다.
- Backend/Frontend 빌드와 테스트가 통과한다.
- 데스크톱과 좁은 모바일 화면에서 오버플로 없이 주요 상태와 동작을 확인한다.
