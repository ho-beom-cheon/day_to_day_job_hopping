# 기능: 비동기 AI 피드백과 사용량 화면 연결

## 범위

- AI 설명·연습문제·오답 분석·일간 피드백·월말 해설 작업 접수
- 사용자 소유 입력 검증, 멱등성, 성공 결과 재사용, 동시 작업·일일 요청 제한
- HTTP 공급자 adapter, timeout, worker, 물리 호출별 사용량 기록
- 작업 단건·목록·오늘 사용량 API와 `/assistant` 일간 피드백 화면
- 공급자 키가 없을 때 명시적인 비활성 상태

## 완료 기준

- 공개 READY/PROCESSING/SUCCESS/FAILED와 내부 상태가 분리된다.
- 공급자 실패가 학습·시험 결과를 되돌리지 않는다.
- 자격증명은 서버 환경변수에만 있고 DB·응답·로그에 저장하지 않는다.
- 실제 공급자 성공은 유효한 로컬 설정으로 검증한 경우에만 완료로 기록한다.
