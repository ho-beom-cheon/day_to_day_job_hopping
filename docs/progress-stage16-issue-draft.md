# 이슈 초안: 진척도 4지표와 월말 평가 Backend

원격 이슈 확인 시도: 2026-09-21 현재 로컬 환경에 GitHub CLI가 없어 확인하지 못함.

## 제목

진척도 4지표와 불변 월말 평가 스냅샷 구현

## 범위

- 전체 과정 완료율, 일정 이행률, 첫 풀이 정답률을 서로 다른 원천과 분모로 계산
- 승인된 숙련도 산식이 없으므로 `masteryRate=null` 유지
- 교육 월차 종료 뒤 원천 기간·분자·분모·분야별 진행·데이터 해시를 월말 평가로 보존
- 동일 데이터 버전 재사용, 새 원천 데이터는 `reportVersion+1`로 추가하고 과거 결과 불변
- 본인 과정만 조회하며 과정이 없을 때 전체 진척 `null`, 목록은 빈 배열/페이지 반환

## 완료 기준

- ID는 JSON 문자열, 비율 산정 불가는 `null`, 실제 0%와 구분한다.
- 일정 이행률은 예정일까지 완료한 필수 세션 / 기준일까지 예정된 필수 세션이다.
- 첫 풀이 정답률은 문제 버전별 최초 일반 연습 제출만 사용하고 재풀이·시험은 제외한다.
- 월말 평가는 교육 월차 종료 전 생성을 거부하고 원천 스냅샷을 수정하지 않는다.
- Backend verify와 실제 PostgreSQL API 검증 결과를 남긴다.
