# 기능: 커리큘럼 배정과 학습 세션·콘텐츠 완료 구현

[이슈 #5](https://github.com/ho-beom-cheon/day_to_day_job_hopping/issues/5)로 등록했다.

## 배경

26단계 계획의 6번이다. OpenAPI v1.2.1의 TEMPLATE-001, CURR-001–006/008, DAY-001–004, SESSION-001–004, CONTENT-001/002를 기존 인증·공통 API·PostgreSQL 기반에 연결한다.

## 범위

- 발행된 템플릿 버전 검증·조회와 사용자당 현재 과정 배정. 휴식 요일을 제외하여 1일 1학습 단위를 배치하고 366일 상한을 검사한다.
- 현재/이전 과정, 교육 월차·주차, 날짜별 학습과 세션·콘텐츠 조회. 날짜는 Asia/Seoul 기준이다.
- 세션 시작, 콘텐츠 읽음/확인 문제 제출 조건, 필수 콘텐츠 완료 후 자기보고 시간과 세션 완료를 저장한다.
- 배정 시 불변 버전 고정, 소유권 검증, 사용자/과정 잠금, 멱등성 및 완료 이벤트의 중복 방지.
- API와 DB의 세션 의미 차이 및 콘텐츠 인스턴스 누락을 후속 V5 migration으로 보완한다. 기존 V1–V4와 개발 데이터를 보존한다.

## 완료 기준 및 검증

- 실제 PostgreSQL HTTP 통합 테스트로 배정·조회·시작·콘텐츠 완료·세션 완료·과정 완료·다음 과정과 이전 이력을 확인한다.
- 다른 사용자 접근, 미발행/불완전 템플릿, 미래 학습 시작, 필수 콘텐츠 미완료, 범위/입력 오류를 거절한다.
- 동시 과정 생성·완료와 동일/상이한 멱등성 요청, rollback, 구버전 이력 보존을 검증한다.
- 신규/업그레이드 migration, 기존 테스트, 개발 서버 적용·smoke를 확인한다.
- 사용자 선택에 따라 실제 운영 콘텐츠는 적재하지 않고 테스트 전용 콘텐츠로 검증한다.

## 범위 제외

휴식·일정 변경 API(7번), 문제 제출 API(8번), 시험 응시·채점(9번), 운영용 학습 콘텐츠 제작, 후속 화면 구현, 커밋/푸시/PR.
