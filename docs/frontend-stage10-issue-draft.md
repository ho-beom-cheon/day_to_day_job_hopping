# 기능: 로그인·온보딩 UI와 최초 과정 배정 흐름 연결

## 배경

작업 5의 Google OIDC·세션 API와 작업 6의 템플릿·과정 배정 API, 작업 9의 Next.js 공통 기반은 준비됐지만 로그인 성공·거부·만료와 신규 사용자의 최초 과정 배정 화면이 연결되지 않았다.

## 범위

- 로그인 전 시작 화면에서 Google 로그인 시작 경로를 제공하고, 로그인된 사용자는 과정 유무에 따라 온보딩 또는 학습 공간으로 이어간다.
- 고정 실패 경로 `/login?error=LOGIN_FAILED|ACCOUNT_NOT_ALLOWED`를 안전한 사용자 문구로 표시하며 임의 공급자 오류는 노출하지 않는다.
- 발행 템플릿 조회, 과정 선택, 시작일, 하루 학습 시간, 정기 휴식 요일을 입력해 최초 과정 배정 API를 호출한다.
- CSRF와 64-bit ID 문자열 경계를 유지하고, 한 논리 요청의 payload와 Idempotency-Key를 네트워크 재시도에도 재사용한다.
- 로그인 만료, 템플릿 loading/error/empty, 배정 처리·실패·중복 과정 상태를 구분한다.
- 과정 배정 후와 새로고침 후 모두 서버의 `curriculumId`에 따라 학습 공간을 복원한다.

## 제외 범위

- 운영 학습 콘텐츠나 템플릿 신규 적재, 공개 회원가입, 비밀번호 로그인.
- 대시보드·오늘 학습·로드맵·휴식일 재조정·문제풀이 화면.
- 설정 화면의 로그아웃 UI와 Google 계정 전체 로그아웃.

## 완료 기준

- OpenAPI `AUTH-001`, 작업 5 고정 실패 경로, `TEMPLATE-001`, `CURR-008` 계약과 일치한다.
- 허용 계정 로그인 성공, 거부/일반 실패, 세션 만료, 템플릿 없음, 과정 배정 성공·실패를 화면에서 구분한다.
- 데스크톱과 좁은 모바일에서 가로 넘침·잘림 없이 주요 동작을 사용할 수 있다.
- typecheck, ESLint, Vitest, production build와 실제 브라우저 검증을 통과한다.
