# 메인페이지 PC 승인 시안

2026-09-21 사용자 확인에 따라 아래 두 이미지를 `/workspace` 메인페이지의 PC 승인 시안으로 등록한다.

## 화면

1. [상단 PC 화면](../design-package/daily_career_codex_implementation_20260919_full/02_assets/images/ui_mockups/core/01a_today_home_dashboard_pc_top.png)
2. [스크롤 하단 화면](../design-package/daily_career_codex_implementation_20260919_full/02_assets/images/ui_mockups/core/01b_today_home_dashboard_pc_scrolled.png)

두 이미지는 별도 페이지가 아니라 같은 메인페이지의 서로 다른 스크롤 위치다.

## 적용 기준

- 현재 PC 레이아웃의 사이드바 폭과 본문 좌우 여백을 유지한다.
- 추천된 학습 콘텐츠, 학습 현황, 인사이트, 최근 활동, 빠른 메뉴, 커리어 목표와 성장 기록을 유지한다.
- 모든 콘텐츠를 첫 화면에 압축하지 않고 자연스러운 세로 스크롤로 제공한다.
- 메인 배너와 상단 프로필을 제외한 카드에서는 캐릭터 이미지를 반복 사용하지 않는다.
- 모바일 시안과 반응형 동작은 별도 기준으로 관리한다.

## 구현 대상

- 페이지: `/workspace`
- 대표 확인 URL: `http://localhost:8080/workspace`
