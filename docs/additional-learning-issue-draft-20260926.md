# 기능: 선택형 추가 학습과 다음 진도 앞당겨 학습

상태: 사용자의 소스 수정 지시에 따라 [GitHub 이슈 #10](https://github.com/ho-beom-cheon/day_to_day_job_hopping/issues/10)을 등록하고 구현했다. 검증 결과와 현재 접속 정보는 [검증 기록](additional-learning-verification-20260926.md), API와 집계 규칙은 [계약](contracts/additional-learning-alignment.md)을 참고한다. 아래 문제와 화면 상태는 구현 전 초안의 근거다.

## 문제

- 현재 학습 화면은 날짜에 배정된 학습 세션을 중심으로 구성되며, 완료 후에는 추가 학습을 고르는 진입점이 없다.
- 휴식일과 배정 없는 날은 일정 화면으로만 안내한다.
- AI 연습은 이미 배정된 콘텐츠에 연결되어 있으며 분야·주제·추가 시간을 독립적으로 선택할 수 없다.
- 미래 학습은 시작 API에서 거절한다. 앞당겨 학습하려면 명시적인 시작 경로와 진도·시간 귀속 규칙이 필요하다.
- 현재 학습 시간은 정규 세션의 배정일에 귀속한다. 추가 활동과 미리 끝낸 학습을 실제 공부한 날짜에 기록하되 중복 합산하지 않아야 한다.

## 사용자 흐름

학습 화면의 `더 공부하기` → 방식 선택 → 제공 가능한 분야·주제 선택 → 15/30/60분 선택 → 본문·예제·실습·문제 학습 → 실제 시간 기록.

1. 오늘 내용 더 익히기: 오늘 배정된 주제의 보충 설명·실습 또는 추가 연습.
2. 다른 분야 공부하기: 공개 가능한 콘텐츠가 있는 분야와 주제를 선택한다. 제공하지 않는 분야를 가능한 것처럼 표시하지 않는다.
3. 복습하기: 이전 학습 내용과 오답을 선택하고 새로운 복습 기록을 남긴다.
4. 다음 진도 이어가기: 현재 과정의 다음 미완료 학습을 명시적으로 시작하고, 완료 시 기존 배정의 완료 상태를 유지한다.

## 데이터와 집계 규칙

- 추가 학습은 선택 활동이다. 시작·중단으로 기본 학습 완료율의 분모나 오늘 완료 상태를 바꾸지 않는다.
- 오늘 기본 학습을 마치지 않았어도 추가 학습을 선택할 수 있다. 휴식일과 기본 학습 완료 후에도 이용 가능하다.
- 목표 시간과 실제 학습 시간을 구분한다. 실제 기록은 서울 날짜 기준 활동일에 귀속하고 통계에 한 번만 더한다.
- 일반 추가 학습은 정규 과정 진도를 변경하지 않는다. `다음 진도 이어가기`로 진행한 정규 세션만 과정 진도에 반영한다.
- 미리 완료한 학습은 예정일에도 완료로 남긴다. 기존 시험 일정과 응시 제한은 유지한다.
- 새로고침·재접속 후 진행 중인 활동과 완료 기록을 복원한다. 중복 시작·완료 및 다른 사용자 접근을 검증한다.
- 문제·해설 공개 시점과 공식 시험 문제의 접근 제한을 유지한다. 추가 학습의 결과를 공식 시험 성적으로 합산하지 않는다.
- AI 생성이 필요한 기능은 생성 중·실패·재시도와 실제 제공 여부를 표시한다. 저장된 자료를 다시 푸는 것을 신규 생성이라고 표시하지 않는다.
- 기존 과정 배정·발행 버전·학습·시험·오답 기록을 보존하고 후속 migration으로 확장한다.

## 완료 기준과 검증

- [x] 네 가지 선택으로 실제 학습 화면에 진입하고 학습·완료 기록이 서버에 저장된다.
- [x] 본문·예제·실습과 문제 풀이를 연결하고 선택 시간에 맞는 범위를 안내한다.
- [x] 미완료 기본 학습일·완료일·휴식일·배정 없는 날에서 추가 학습을 시작한다.
- [x] 추가 활동의 시작·중단·완료가 필수 진도와 완료율을 바꾸지 않는다.
- [x] 앞당겨 완료한 세션의 진도를 인정하고 예정일에 다시 필수로 요구하지 않는다.
- [x] 실제 활동일별 시간과 누적 시간을 중복 없이 집계한다.
- [x] PostgreSQL 통합 검증으로 소유권·멱등성·동시 요청·시간 귀속·정규 진도 회귀를 확인한다.
- [x] 프런트엔드 타입·린트·관련 테스트·빌드와 실제 브라우저의 데스크톱·모바일 흐름을 확인한다.
- [x] 실제 검증한 URL, 실행 상태, 시작 명령과 미검증 범위를 완료 보고에 기록한다.

## 현재 확인 가능한 화면

[대표: 기존 QA 학습 화면](http://localhost:18081/learning)

2026-09-26 19:01 KST 브라우저에서 직접 확인했다. 서비스는 실행 중이며 포트는 18081이다. 별도 QA DB의 `과정 검증 사용자`가 자동 적용된다. 현재 화면은 1일차 학습 완료·90분 기록을 표시하며 추가 학습 기능은 아직 없다.

재시작은 Docker Desktop과 기존 QA 이미지·DB, 추적 제외 `.env.course-qa.local`이 준비된 환경에서 다음 명령을 사용한다. 이 단계에서는 서비스를 재시작하거나 DB를 변경하지 않았다.

```powershell
docker compose --env-file .env.course-qa.local -f compose.course-qa.yaml up -d --wait
```
