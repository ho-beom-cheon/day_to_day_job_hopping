# 작업 17 진척도·평가 UI 검증

## 구현 결과

- `/progress` route와 앱 셸의 성장 메뉴를 활성화했다.
- 전체 과정, 네 핵심 지표, 누적 학습시간·연속일, 분야별 진행, 월말 평가 이력을 연결했다.
- `null` 지표는 `평가 전`, 실제 0은 `0%`로 구분한다.

가짜 운영 seed는 만들지 않았다. 승인된 템플릿이 발행되면 `/progress`에서 데스크톱·320px 화면, 가로 넘침, 콘솔 오류를 최종 확인해야 한다.
