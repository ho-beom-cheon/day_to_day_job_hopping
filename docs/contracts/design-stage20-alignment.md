# 작업 20 디자인 시스템·전체 화면 채택 기준

## 기준

- 핵심 시안 10종의 정보 계층, 내비게이션, 카드 밀도, 상태 표현을 우선한다.
- 실제 API와 저장 상태가 없는 수치·활동·콘텐츠는 만들지 않는다.
- 데스크톱은 좌측 내비게이션과 확장 본문, 모바일은 상단 브랜드와 하단 5개 내비게이션을 사용한다.
- 공통 색상·배경·테두리·카드 반경·그림자·포커스 링은 `globals.css` 토큰을 기준으로 한다.
- 키보드 포커스는 링크, 버튼, 입력, 선택, details summary에서 항상 식별 가능해야 한다.
- 320px 이상에서 가로 스크롤이 없어야 하며 주요 조작 영역은 최소 44px 높이를 유지한다.
- loading, empty, error, disabled, processing 상태를 실제 업무 상태와 구분한다.

## 이번 보완

- 사용자 승인 메인페이지 PC 시안을 `01a_today_home_dashboard_pc_top.png`와 `01b_today_home_dashboard_pc_scrolled.png` 두 장으로 등록했다.
- 두 시안은 같은 `/workspace` 페이지의 상단과 스크롤 하단이며, 실제 PC 폭의 본문 최대 너비와 좌우 여백을 구현 기준으로 사용한다.
- 추천 콘텐츠와 데이터 영역은 유지하고, 한 화면에 압축하지 않으며 세로 스크롤과 넉넉한 카드 간격으로 정보 밀도를 조절한다.
- 캐릭터 이미지는 메인 배너와 상단 프로필로 제한한다.
- 홈을 시안형 데스크톱 2열·모바일 단일열 구조로 재구성했다.
- 데스크톱 사이드 메뉴와 모바일 `홈·학습·시험·성장·더보기`를 시안 구조로 맞췄다.
- 모바일 더보기 바텀시트에서 전체 메뉴, 준비 중 상태, 설정·고객센터를 제공한다.
- 울트라와이드 본문 폭과 빈 상태의 세로 공백을 보완했다.
- 공식 캐릭터 시트를 기준으로 생성한 홈 전용 배너를 사용한다.
- 전역 디자인 토큰과 키보드 포커스·disabled·reduced-motion 규칙을 추가했다.

## 완료 경계

작업 20은 진행 중이다. 시안 10은 작업 18이 구현된 뒤, 연동 설정은 동시에 진행 중인 작업 19가 빌드·계약 검증을 통과한 뒤 화면 대조와 실제 오류·부분 실패 상태를 확인해야 완료할 수 있다. 운영 콘텐츠가 없어 데이터가 채워진 화면의 전체 브라우저 비교도 작업 21 통합 검증과 함께 보완한다.
