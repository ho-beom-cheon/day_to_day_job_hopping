# 작업 17 진척도·평가 UI 계약 대조

## 적용

- 시안 `08_progress_growth_analysis.png`의 전체 진행 원형, 핵심 지표 카드, 분야별 막대, 학습시간 위계를 재사용했다.
- 전체 과정 완료율과 분야별 `progressRate`만 진행 막대로 표현한다.
- 일정 이행률, 과정 완료율, 숙련도, 첫 풀이 정답률은 이름과 설명을 분리했다.
- 숙련도 정책 미확정과 첫 풀이 표본 없음은 `평가 전`으로 표시한다.
- 월말 평가는 교육 월차, 보고서 버전, 기간, 완료율, 월간 시험 존재 여부를 표시한다.

## 시안과의 차이

- 주간/월간/연간 탭은 기간 API를 이번 화면에서 연결하지 않아 제거했다.
- 지난주 대비 수치와 누적 격려 수치는 비교 기준 계약이 없어 만들지 않았다.
- 시안의 숙련도 예시 68%는 승인된 산식이 아니므로 사용하지 않았다.
