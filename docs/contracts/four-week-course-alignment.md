# 4주 과정 계약 정렬 — #9

원본 설계 패키지는 보존한다. 이 문서가 기존 6개월 고정 계약의 변경과 호환 범위를 기록한다.

- `CurriculumTemplate.durationMonths`: 6 고정에서 1~6으로 확장. 월 모듈 개수는 이 값과 일치해야 한다. DB 원형 컬럼은 더 넓은 범위를 허용하지만 현재 학습 서비스의 지원 범위는 1~6이다.
- `Curriculum.durationMonths`: 정수 필드 추가. 배정에 고정된 curriculum_version에서 읽는다. 구형 응답을 읽는 프런트엔드는 누락 시 이전 계약인 6을 적용한다.
- `nominalEndDate`: 시작일+템플릿 durationMonths-1일. 기존 6개월의 계산과 저장 기록은 변하지 않는다. `endDate`는 휴식 요일을 제외한 실제 배정 마지막 날짜다.
- `schemaVersion: 1` 원고 적재 도구는 1개월/4주/20학습일 전용이다. 1~6개월 모든 형태를 임의로 자동 생성하는 도구가 아니다.
- 교육 주차는 실제 달력 주와 다르다. 20일을 주 5일로 배정하면 4주 분량이며, 휴식 정책에 따라 실제 종료일은 달라진다.
- 온보딩은 1개월·4주·20학습일을 표시한다. 6개월 미완성 경고를 4주 독립 과정에 표시하지 않는다.
- 완료율 분모는 시험을 제외한 필수 학습 세션이다. 기존 시험 완료·성적 집계는 별도 계약이다.
- 학습 통계의 시간은 배정된 세션의 완료 시 입력한 `actualMinutes`를 사용하며 배정 학습일에 귀속한다. 기존 timer 기록은 배정 상세가 없는 세션에만 더해 중복 합산을 막는다. 완료한 과정도 조회한다.
- 연속 학습일은 서울 날짜 기준으로 미래 배정일을 제외한다. 오늘이 아직 미완료이면 전 학습일까지의 연속 기록을 유지하고, 과거 미완료 학습일에서 끊는다. 휴식일은 제외한다.
- 시험 저장소의 `QUEUED`는 공개 응답의 `WAITING`으로 변환한다. 제출 성공 응답과 채점 이벤트가 같은 공개 상태를 사용한다.
- 시험 화면은 목록의 전체 페이지를 읽는다. 기본 페이지 크기 20 때문에 마지막 주와 최종 시험이 숨겨지지 않는다.
- 기존 버전과 사용자 배정은 불변으로 유지한다. 새 발행은 신규 템플릿을 추가하며 재시작·자동 교체·진척 초기화를 수행하지 않는다.
- 시험 서비스도 학습 서비스와 동일한 Clock을 주입받는다. 운영 시 시스템 서울 시각을 사용하고 통합 테스트에서는 경계를 고정한다.

원고 적재 이력은 V19의 `catalog_import`에 기록한다. 외부 코드+버전과 정규화 JSON SHA-256, DB 구성 SHA-256을 사용한다. 하위 문제 ID 대응은 JSON 문자열이다. 운영자 도구는 웹 API를 추가하지 않는다. 검수 없는 DRAFT는 일반 publish로도 발행할 수 없다.
