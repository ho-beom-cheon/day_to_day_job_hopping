# 선택형 추가 학습 계약

관련 이슈: [#10](https://github.com/ho-beom-cheon/day_to_day_job_hopping/issues/10)

## 화면과 범위

`/learning`의 **더 공부하기**는 `/learning/extra`로 이동한다. 기본 학습 완료 여부와 관계없이, 휴식일·배정 없는 날에도 현재 과정이 있으면 이용할 수 있다.

| 방식 | 선택 범위 | 정규 진도 |
| --- | --- | --- |
| DEEPEN | 오늘 배정된 공개 학습 자료 | 변경하지 않음 |
| EXPLORE | 발행된 과정에 연결된 공개·활성 학습 자료 | 변경하지 않음 |
| REVIEW | 사용자가 시작한 학습 자료, 미해결 오답이 있는 주제 우선 | 변경하지 않음 |
| AHEAD | 현재 과정의 다음 미래 미완료 정규 학습 | 기존 세션 완료에 반영 |

15/30/60분은 예상 소요 시간이다. 일반 추가 학습은 기존 본문·예제·실습과 최대 3/6/10개의 확인 문제를 제공한다. 저장된 문제를 신규 생성 문제라고 표시하지 않는다. AI 연습은 기존 생성 기능을 별도로 요청한다. AHEAD는 기존 세션의 필수 콘텐츠와 문제 범위를 유지하며 선택한 예상 시간만큼 나누어 공부할 수 있다.

## HTTP API

모두 인증이 필요하며 ID는 JSON 문자열이다. POST에는 기존 CSRF와 Idempotency-Key 규칙을 적용한다.

| 요청 | 동작 |
| --- | --- |
| GET `/api/v1/extra-learning/topics?mode=DEEPEN` | 해당 방식에서 시작 가능한 주제 |
| GET `/api/v1/extra-learning` | 자신의 추가 학습 기록과 이어하기 |
| GET `/api/v1/extra-learning/{sessionId}` | 해당 세션의 추가 학습 정보, 일반 세션이면 null |
| POST `/api/v1/extra-learning` | `mode`, `contentVersionId`, `sourceSessionId`, `targetMinutes`로 시작; EXTRA-001 |
| POST `/api/v1/extra-learning/{sessionId}/time` | 아직 저장하지 않은 `actualMinutes` 누적; EXTRA-002 |

AHEAD는 `sourceSessionId`만, 나머지 방식은 `contentVersionId`만 지정한다. 일반 추가 학습은 같은 과정·방식·자료·목표 시간의 진행 중 세션을 중복 생성하지 않는다. 사용자와 과정 잠금으로 서로 다른 요청 키의 동시 시작도 직렬화한다.

기존 문제 조회 API의 선택적 `contentId`와 `/practice/{problemId}?contentId=...` 링크로 정규 학습과 추가 학습의 풀이 문맥을 구분한다. 일반 추가 학습은 자신의 배정 콘텐츠에서 제출한 답안만 완료 조건으로 인정한다. 그 답안을 이후 정규 학습의 완료 조건에 자동 사용하지 않는다. AHEAD는 원래 정규 학습 문맥을 유지한다.

## 저장과 집계

- V21 migration으로 `extra_learning`, `extra_learning_time`을 추가한다. 기존 과정·콘텐츠·시험 기록을 초기화하지 않는다.
- V22·V23은 세션 시간 출처를 보관하며 실제 기록이 없는 행을 `NOT_RECORDED`로 표시한다.
- 일반 추가 학습은 `required=false`인 선택 세션이다. 현재 날짜 행을 재사용하되 휴식 상태를 바꾸지 않는다. 배정 없는 날짜는 과정 일차가 없는 선택 활동용 행을 생성한다.
- 정규 학습 목록·완료율·분야별 정규 진도·필수 학습일 수에서 선택 세션을 제외한다. 추가 공부만 했다고 기본 학습 완료율의 분모를 늘리지 않는다.
- 새 화면은 시간을 다시 입력받지 않는다. 완료할 때 선택한 예상 시간을 `actual_minutes`에 복사하지 않는다. 완료한 세션의 예상 시간 합은 별도 `completedEstimatedMinutes` 지표로 보여주며 실제 공부 시간으로 부르지 않는다.
- 이전 클라이언트의 직접 입력 API는 호환을 위해 유지한다. 과거 자기보고 시간과 풀이 기록도 보존한다.
- 전체 학습 활동은 과정 재시작 전후 추가 학습 완료 수, 기본 확인 문제 제출·정답 수, AI 확인 문제 제출·정답 수를 별도로 보여준다. 오답노트도 이전 과정의 저장된 오답을 조회한다.
- AHEAD는 원래 배정일을 유지한다. 미리 완료하면 예정일에도 완료이며, 선택한 시간은 예상 시간으로만 남는다. 시험 일정과 응시 제한은 유지한다.
- 휴식일에 추가 공부한 후 휴식을 취소하거나 정책을 변경해도 선택 세션·풀이·시간을 보존한다. 선택 활동만 시작한 날은 정규 일정 변경을 잠그지 않는다.

기존 학습 세션 API의 시작·본문·완료 흐름을 그대로 사용하므로 재접속 후 이어서 공부할 수 있다. 새 문제 생성이나 모든 분야의 콘텐츠 공급을 보장하는 기능은 아니다.
