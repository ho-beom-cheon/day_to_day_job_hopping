# 작업 16 진척도·월말평가 계약 대조

## 채택 기준

| 지표 | 원천과 계산 | 산정 불가 |
|---|---|---|
| 일정 이행률 | 조회 기준일까지 예정된 필수 세션 중 예정일까지 완료한 수 | 예정 대상이 없으면 `null` |
| 과정 완료율 | 완료 필수 세션 / 배정 당시 전체 필수 세션 | 분모가 없으면 `null` |
| 숙련도 | 문제·시험 공식 채점 결과를 결합할 승인된 버전 정책 | 정책 미확정이므로 `null` |
| 첫 풀이 정답률 | 문제 버전별 최초 `PRACTICE` 제출 중 현재 공식 채점 정답 수 | 최초 제출 표본이 없으면 `null` |

## 월말 평가

- OpenAPI의 최신 설명대로 달력 월이 아니라 교육 `monthNo` 범위를 사용한다.
- `metrics_snapshot`에 기간, 분자·분모, 비율, 학습시간, 분야별 지표, 데이터 버전을 고정한다.
- `dataVersion`이 같으면 기존 평가를 반환하고, 달라지면 새 `reportVersion`을 추가한다.
- 작업 14의 MONTHLY 시험 결과가 없는 현재 상태는 `assessmentStatus=INSUFFICIENT_DATA`, `monthlyTestScore=null`이다.
- AI 보고서는 작업 18 범위이므로 이번 단계에서는 근거 없는 강점·취약점·종합점수를 만들지 않는다.

## 남은 정책

숙련도 가중치와 문제·시험 결합 방식은 미확정이다. 정책 승인 전에는 첫 풀이 정답률이나 완료율로 대신하지 않는다.
