# 작업 14 이슈 초안 — 시험·제출·채점 Backend

## 목표

시험 조회·응시 생성·답안 자동 저장·멱등 제출·비동기 채점·결과 조회를 OpenAPI와 PostgreSQL 계약에 맞춰 제공한다.

## 완료 조건

- 시험 전 정답 비노출과 응시 시점 스냅샷 고정
- 소유권, 응시 가능 시간·횟수, 활성 응시 중복 차단
- If-Match 답안 저장과 Idempotency-Key 시작·제출
- 제출과 채점 트랜잭션 분리, 실패 제출 보존, 새 run 재채점
- 기존 Flyway 불변 유지 및 실제 PostgreSQL V7 적용
