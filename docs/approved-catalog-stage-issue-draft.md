# 기능: 승인 개발용 커리큘럼·문제·시험 데이터 준비

## 배경

기능 6·8·14와 화면은 구현됐지만 검토된 공통 카탈로그가 없어 실제 학습·문제·시험 성공 흐름을 시작할 수 없다.

## 범위

- `dev-seed` profile에서만 적용되는 결정적 Flyway migration
- 6개월 과정, 본문 6개, 객관식 문제 6개, 4종 시험
- 애플리케이션 카탈로그 검증기와 실제 PostgreSQL 재실행 검증

## 제외

- 실제 사용자, 풀이, 오답, 진척 기록
- production profile·migration·외부 자격증명 변경
- 서술형·코드·AI 채점 콘텐츠

## 완료 조건

- clean PostgreSQL에서 전체 migration과 seed가 성공한다.
- 카탈로그 발행 규칙과 재실행 멱등성을 통과한다.
- 개발 서비스에서 과정 배정 후 로드맵·학습·문제·시험 화면을 열 수 있다.
