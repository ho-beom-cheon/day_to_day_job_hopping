# 이슈 초안: 문제 풀이·오답노트·복습 UI 연결

원격 이슈 확인 시도: 2026-09-21 현재 로컬 환경에 GitHub CLI가 없어 확인하지 못함.

## 제목

문제 풀이와 오답 복습 사용자 흐름 구현

## 범위

- 작업 8의 문제 조회·답안 제출·오답 목록/상세·메모·해결/재복습 API 연결
- 문제 유형별 답 선택, 제출 후 정답·해설, 첫 풀이와 재풀이 안내
- 오답 상태 필터, 상세 해설, 개인 메모, 수동 해결과 다시 복습 흐름
- 작업 9의 SessionGate, API client, 오류/상태 UI, 반응형 앱 셸 재사용
- 시험 Backend/API/화면과 공통 시험 계약은 제외

## 완료 기준

- 문제 제출 전에는 정답과 해설을 표시하지 않고 제출 후 결과에 따라 구분한다.
- 재풀이는 첫 풀이 지표와 별도임을 화면에서 명시한다.
- 오답의 미해결/해결 상태와 해결/재복습 액션을 구분한다.
- 메모 수정은 ETag/If-Match를 사용하고 stale/precondition 오류는 공통 최신 정보 재조회 UX로 처리한다.
- 64-bit 업무 ID는 TypeScript에서 문자열로 유지한다.
- 모바일 320px 이상에서 가로 넘침 없이 사용할 수 있다.
