# 완료한 학습량 기반 평가 연결 — 2026-09-27

관련 이슈: #10 / #8. 사용자의 정규·추가 학습에 비례한 일간·주간·월간 평가 적용 요청.

## 구현

- V32는 기존 학습·답안·시험을 수정하지 않고 완료 원문별 교육 일/주/월 귀속 기록과 평가/회차 테이블을 추가한다. 이미 완료한 자료는 기존 완료 시각으로 이관한다. 이후 일정 변경이 과거 완료 귀속을 바꾸지 않는다.
- 실제 완료한 `assigned_content`의 핵심 목표를 수집한다. 동일 원문 버전의 동일 목표를 중복 계산하지 않으며 개인 AI 원문도 소유권·발행·자동 검사 이력을 확인한다. 출처 부족은 실패로 표시하고 범위를 조용히 축소하지 않는다.
- 일간은 완료 날짜, 주간은 교육 주, 월간은 교육 월, 최종은 현재 과정 전체를 기준으로 한다. 추가 학습/미리 학습도 실제 완료 날짜에 귀속한다. 월말 주간과 마지막 학습일의 일간은 상위 평가로 대체한다.
- 목표마다 객관식/단답/면접 답변 문항을 배정한다. 선택한 30/60/90/120분에서 일간 30%, 주간 50%, 월간 70%, 최종 100%를 회차 상한으로 사용한다. 풀이와 해설 시간을 합산하며 초과 분량은 회차로 분리한다. 공급자 호출은 회차별 최대 6문항이다.
- 생성한 평가의 범위는 고정한다. 이후 새로 완료한 목표는 별도 평가로 만든다. 같은 기간 주간/월간 범위에는 정규·추가 목표 전체가 합산된다. 전체 회차 제출 후 같은 범위의 새 문제 재응시를 제공한다.
- 실제 OpenAI 작업 큐에 STUDY 일간/주간/월간/최종/재응시/채점을 연결했다. 생성 입력에는 원문/목표/서버 계획만 전달하고 과거 답안·정답률·계정 식별자를 제외한다. 채점 입력은 현재 서술형 문항과 현재 제출 답안으로 제한한다.
- 평가 시작 전/제출 전 정답·해설·루브릭은 API에서 숨긴다. 일반 AI 작업 조회에서도 평가 결과를 숨긴다. 서버 제한 시간, 답안 리비전, 자동 저장, 제출 후 불변 처리, 객관식 결정적 채점과 서술형 HOLD를 적용했다. 응답 없는 문항은 0점, 판정 불가 답변은 점수 미확정이다.
- `/tests`에 실제 학습 평가를 배치하고 기존 배정 시험/연습 기록은 접을 수 있는 영역에 보존했다. 학습 완료 후 같은 시험 화면으로 연결한다.
