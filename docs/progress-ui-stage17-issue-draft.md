# 이슈 초안: 진척도·월말평가 UI

원격 이슈 확인 시도: 2026-09-21 현재 로컬 환경에 GitHub CLI가 없어 확인하지 못함.

## 제목

성장 화면에 네 지표와 월말 평가 이력 연결

## 범위

- `/progress` 성장 화면과 앱 셸 메뉴 활성화
- 전체 과정 완료, 일정 이행, 숙련도, 첫 풀이 정답률을 독립 라벨로 표시
- 분야별 완료 진행과 월말 평가 최신 이력 표시
- loading/empty/error 및 평가 전 상태, 320px 이상 반응형 레이아웃

## 완료 기준

- `null`은 0%가 아니라 `평가 전`으로 표시한다.
- 시안의 정보 위계를 재사용하되 서버에 없는 비교 수치나 종합점수는 만들지 않는다.
- ID 문자열 decoder와 평가 상태를 런타임에 검증한다.
- test/typecheck/lint/build와 실제 브라우저 데스크톱·모바일 검증 결과를 남긴다.
