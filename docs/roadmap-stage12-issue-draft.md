# 이슈 초안 — 로드맵·휴식·일정 변경 UI

## 사용자 가치

- 배정된 6개월 과정의 월·주별 기간과 진척을 한 화면에서 확인한다.
- 특정 날짜의 휴식 추가·해제, 정기 학습 정책 변경, 밀린 일정 재배치를 실제 반영 전에 확인한다.
- 이동 학습일 수와 종료일 변화를 확인한 뒤에만 확정하며, 다른 탭에서 일정이 바뀌면 최신 일정으로 다시 검토한다.

## 포함 범위

- `/roadmap` 인증 route와 6개월 월/주 로드맵
- CURR-003/004/005 조회 decoder, mapper, Query 경계
- CURR-009 preview와 CURR-007, REST-001/002 confirm
- 휴식 사유·정책 요일/시간 입력, preview 만료·재진입·stale 처리
- 기능 단위 계약/모델/Query 테스트와 반응형 빌드 검증

## 제외 범위

- 작업 10 로그인·과정 배정 화면, 작업 11 오늘 학습 화면
- Backend API·DB·일정 이동 정책 변경
- 일정 변경 이력 목록 API 신설과 서버 저장 draft
- 작업 20의 전체 시안·캐릭터 최종 보완
