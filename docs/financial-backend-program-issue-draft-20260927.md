# 기능: 금융권 백엔드 26주 통합 학습·평가 프롬프트와 운영 계약 적용

2026-09-27 사용자가 대화에서 설계를 확정하고 현재 프로젝트 적용을 승인했다. 관련 원격 이슈 #9(4주 과정), #10(추가 학습), #8(AI 연동)를 읽었으며 이번 통합 범위는 별도 이슈 초안으로 관리한다. 원격 이슈 등록·커밋·푸시는 이번 요청에 포함하지 않는다.

## 문제

기존 4주 원고 스키마와 객관식 연습 생성만으로 26주 혼합 커리큘럼, 선택 시간 내 학습·평가, 목표 전체의 평가, 면접 답변 채점과 재응시를 표현할 수 없다. 목차·프롬프트·학습 원문·검수·발행·실제 응시는 각각 다른 준비 단계다.

## 범위

### 2026-09-27 후속 수정: 완료한 자료로 평가를 준비할 수 없는 문제 (#10 / #8)

사용자가 완료한 SQL/Spring 옛 원문과 추가 학습 원문의 검수 경로 누락 때문에 전체 평가가 차단된다. 원문·완료·답안은 보존하고, 검토된 발행본의 digest에 한정해 기존 원문/확인 문제/정답 해설을 평가 근거로 연결한다. 학습 목표를 추가하거나 제외하지 않는다. 추가 학습 목록과 평가에 공통 준비 기준을 적용하고, 예외 상태에는 구체적 자료와 원인을 표시한다. 실제 사용자와 같은 5원문/11목표 회귀, 기간별 준비·기록 보존·실사용 배포를 검증한다.

- [x] V33 근거 연결, 공통 준비 판정, 예외 자료별 안내
- [x] 5원문/11목표 준비 및 원본 보존 회귀, 실사용 배포
- 외부 생성과 실사용 자동 로그인은 승인 검토 차단으로 이번 검증 범위에서 제외. [상세 검증](study-source-readiness-fix-20260927.md).

### 2026-09-27 추가 요청: 실제 학습량에 따른 평가 연결 (#10 / #8)

완료한 정규·추가 학습의 목표를 실제 일간·주간·월간·최종 평가 생성, 응시, 저장, 채점에 연결한다. 같은 목표는 중복 계산하지 않고, 시간 한도를 넘는 범위는 회차로 나눈다. 시작한 평가의 범위와 답안은 고정하며 이후 추가 목표는 별도 평가로 이어진다. 기존 시험·답안은 보존한다. 월간 범위는 해당 교육 월만 포함하고 주간/월간 평가일의 중복 일간 평가를 대체한다. 개인 원시 통계는 생성 공급자에 전송하지 않는다.
