# 작업 11 이슈 초안 — 대시보드·오늘 학습 UI

## 목표

로그인한 사용자가 실제 배정 과정과 오늘 학습을 확인하고, 학습 세션을 시작해 콘텐츠와 세션을 완료한 뒤 갱신된 진행률을 다시 확인할 수 있게 한다.

## 포함 범위

- 현재 과정과 오늘 학습 API를 조합한 대시보드
- 과정 완료율, 오늘 진행률, 평가 전 지표의 구분
- 학습일 없음, 휴식일, 로딩, 오류, 완료 상태
- 세션 상세, 세션 시작, 콘텐츠 완료, 실제 학습 시간 기반 세션 완료
- 완료 요청의 멱등성 키 보존과 성공 후 관련 캐시 갱신
- 데스크톱·모바일 반응형 화면과 키보드 포커스

## 제외 범위

- 아직 Backend에 없는 `DASH-001 /api/v1/dashboard` 구현
- 작업 10 로그인·온보딩, 작업 12 로드맵·일정 변경, 작업 13 문제·복습
- 작업 16의 숙련도·첫 풀이 정답률 계산
- 운영 학습 콘텐츠 작성 또는 적재

## 완료 기준

- 완료된 작업 6 API만 사용해 실제 과정·오늘 학습 데이터를 표시한다.
- 문자열 ID를 숫자로 변환하지 않는다.
- 분모가 없거나 계산 기능이 아직 없으면 0% 대신 `평가 전`을 표시한다.
- 재시도 동안 세션 완료 요청의 payload와 Idempotency-Key를 유지한다.
- 관련 단위 테스트, 타입 검사, 범위 린트와 실제 브라우저의 접근 가능한 상태를 확인한다.
