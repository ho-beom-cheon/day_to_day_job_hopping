# Notion 연동 최종 기준 복원본

## 방향

- PostgreSQL = 원본
- 앱 → Notion 단방향
- Notion이 업무 DB를 직접 수정하지 않음
- 동기화는 비동기

## 핵심 동기화 대상

- 문제/풀이 기록
- 시험/결과
- 오답노트
- 월말 평가
- 필요 시 학습 기록

경력/채용 데이터는 웹앱 핵심 업무 스키마로 확정된 범위와 구분한다. 화면/API가 확정되지 않은 영역을 임의로 업무 테이블에 추가하지 않는다.

## 실패 처리

`업무 저장 → outbox → sync_job → sync_attempt → Notion`

- 업무 성공과 동기화 성공을 분리
- PARTIAL_SUCCESS/FAILED에서 실패 항목만 재처리 가능
- 이미 성공한 항목을 중복 생성하지 않음
- UI는 연결/동기화/부분실패/재처리 상태를 구분
