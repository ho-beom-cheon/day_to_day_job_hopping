# 데일리 이직 기능 설계 최종 기준

## 목적

금융·공공 SI 경력을 가진 개발자가 6개월 동안 매일 학습하고 시험·복습·평가를 반복하여 상향 이직을 준비하는 개인 교육 웹앱이다.

## 핵심 기능

1. Google 로그인 및 개인 세션
2. 6개월 커리큘럼 배정/조회
3. 오늘의 학습 및 학습 세션
4. 학습 콘텐츠 완료 처리
5. 문제 풀이 및 정답/해설
6. 오답노트 및 복습 예약
7. Daily / Weekly / Monthly / Final 시험
8. 시험 제출/비동기 채점/결과 조회
9. 월말 평가
10. 휴식일 및 학습 일정 조정
11. 진척도 및 성장 분석
12. AI 학습 도우미/피드백
13. 웹 푸시, Slack 알림
14. Notion 문제/시험/오답/평가 동기화
15. 사용자/연동 설정

## 학습 운영

- 기본 주 5일 학습 + 2일 휴식
- 사용자가 휴식 횟수와 요일을 조정 가능
- 일정 변경으로 완료 이력이나 콘텐츠 버전 식별자가 바뀌면 안 됨
- 미래 미시작 학습만 재배치
- 기본 재배치 정책은 종료일 연장

## 시험

- 시험 유형: DAILY / WEEKLY / MONTHLY / FINAL
- 답안 임시저장 및 revision 관리
- 제출 상태와 채점 상태 분리
- 서술형/AI 채점 실패 시 제출 데이터 유지
- 재채점은 별도 이력으로 남김

## 진척도

- 일정 이행률: adherenceRate
- 전체 커리큘럼 완료율: completionRate
- 문제·시험 기반 숙련도: masteryRate
- 첫 풀이 정답률: firstAttemptAccuracy

## 외부 서비스

PostgreSQL이 업무 원본이다. Notion/Slack/Web Push는 비동기 연동이며 외부 실패가 원본 업무를 취소하지 않는다.
