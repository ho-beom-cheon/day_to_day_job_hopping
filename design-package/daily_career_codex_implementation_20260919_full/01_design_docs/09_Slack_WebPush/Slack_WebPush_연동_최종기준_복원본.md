# Slack / Web Push 연동 최종 기준 복원본

## 공통 원칙

Slack과 Web Push는 학습/시험 등 핵심 업무의 부가 알림 채널이다.

- 핵심 업무 트랜잭션과 외부 전송 분리
- PostgreSQL/outbox에 발송 의도를 기록
- 워커/비동기 처리로 외부 전송
- 실패 시 재시도/운영 확인 가능
- 외부 실패로 핵심 업무를 롤백하지 않음

## UI

- 연결/권한 상태
- 발송 설정
- 최근 성공/실패 상태
- 필요 시 재시도/재연결 안내

## 보안

Webhook/토큰/Push subscription의 민감값을 클라이언트 로그나 일반 API 응답에 노출하지 않는다.
