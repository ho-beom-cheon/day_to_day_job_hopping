# 데일리 이직 UI/UX v0.3 최종 기준

## 범위

- 독립 화면: 43
- 팝업/바텀시트/오버레이: 22
- 총 UI 본: 65
- 공통 컴포넌트 체계 포함
- 기존 설계의 사용자 동작/입력 원문과 ID를 보존하면서 상태 UX를 보강

## 디자인 방향

- 밝은 배경
- 블루/퍼플 포인트
- 충분한 여백
- 둥근 카드
- 얇고 부드러운 그림자
- 모바일 우선 반응형
- 공식 캐릭터는 학습 동기부여/성공/휴식/AI 피드백 맥락에서 제한적으로 사용

## 필수 상태

- Loading
- Empty
- Error
- Disabled
- Completed
- Processing
- Conflict/Stale
- External Sync Partial Failure

## 시험 UX

다음 상태를 합치지 않는다.

- 응시 중
- 제출 완료
- 채점 중
- 채점 완료
- 채점 실패

## 일정 UX

- 변경 영향 미리보기
- 변경 전/후 종료일
- 이동되는 미래 학습 범위
- confirm
- stale revision 충돌 시 재조회 안내

## 진척 UI

다음 지표를 서로 다른 라벨/정보구조로 노출한다.

- 일정 이행률
- 전체 과정 완료율
- 숙련도
- 첫 풀이 정답률

분모가 없으면 임의 0%가 아니라 `평가 전` 또는 null 기반 표현을 사용한다.

## AI UX

- 생성 준비/처리 중/성공/실패
- 사용자 취소 버튼 없음

## 외부 연동 UX

Notion/Slack/Web Push의 연결 상태 및 동기화/발송 상태는 핵심 업무 성공 상태와 분리한다.
