# 핵심 시안 10종 완료 목록

사용자 확인 기준으로 개발 착수 전 핵심 시안 10종은 완료 처리한다.

1. 오늘 홈 / 대시보드
2. 6개월 커리큘럼 / 로드맵
3. 오늘 학습 상세
4. 문제 풀이
5. 시험 현황
6. 시험 응시
7. 시험 결과 / 오답 분석
8. 진척도 / 성장 분석
9. 휴식일 / 일정 변경
10. AI 학습 도우미 / 피드백

## 개발 적용

나머지 화면은 v0.3 상세 화면설계와 이 10개 시안에서 확정된 디자인 시스템을 재사용하여 구현한다.

### 오늘 홈 PC 시안 보완 등록 (2026-09-21)

- 상단 화면: `../../02_assets/images/ui_mockups/core/01a_today_home_dashboard_pc_top.png`
- 스크롤 하단 화면: `../../02_assets/images/ui_mockups/core/01b_today_home_dashboard_pc_scrolled.png`
- 두 이미지는 하나의 메인페이지를 위·아래 스크롤 위치로 나눈 승인 세트다.
- 실제 PC 폭의 좌우 여백과 본문 최대 너비를 유지하고, 콘텐츠를 삭제하지 않은 채 세로 스크롤로 배치한다.
- 캐릭터 이미지는 메인 배너와 상단 프로필에만 사용한다.
